Design V4 (CREATIVE_DIRECTION.md §3.7): the same single form, saved in ONE post (the legal flow does not change, §89), drawn as a guided form — a Stepper of the questions at the start of the row, one question at a time on a level-2 panel in the middle, a sticky glass foot with «Précédent» · «Continuer» and the form's submit. Without JavaScript the questions simply follow each other; situation.js is a progressive enhancement (it hides the other questions, never the fields from the submission). Two things this page must make visible, because both are promises the project has made: 1. WHY each question is asked. Every field carries its own reason, supplied by the form, and the page states the general one above them. A question whose answer nothing reads has no business being here, and saying so is the only way that constraint stays true over time. 2. WHAT changes when the answers change. Saving re-runs the rules in force against the new facts, so the orientation moves on the same visit. The page says this before the form rather than after it, because a person deciding whether to answer a question about their circumstances is entitled to know what it will be used for first. Deliberately absent: any progress bar, score or percentage of "profile strength". The counter says how many questions have an answer. It is a count of answers, never a judgement about the person. The Stepper's filled nodes are the same count, question by question — the profile's own `answered()` rule, not a second one. {% endcomment %} {% block page_title %}{% translate "Ma situation" %}{% endblock %} {% block meta_description %}{% translate "Les informations que vous nous communiquez sur votre situation, et ce qu’elles servent à déterminer." %}{% endblock %} {% comment %}The page's one page-only sheet (the owner's V5.8: never in the shared bundles), after the shell's two: the guided form (W3-F1's v5/_wizard.css — the w3-d merge took it out of console.css) and its Stepper (W3-D).{% endcomment %} {% block extra_head %}{{ block.super }}{% endblock %} {% block case_header %}{% endblock %} {% block next_action_block %}{% endblock %} {% block portal_header %}
