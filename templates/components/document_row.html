{% load i18n %}{% comment %} DocumentRow (design V4, CREATIVE_DIRECTION.md §3.5.4, DESIGN_SYSTEM_V4.md §8.24): one required piece of a case file as a row of seven zones — identity · state · responsible · due date · health · action · menu — inside a DocumentCollection sheet. Below 48rem the same markup stacks as a card (v4/workspace.css); there is no second template for the phone. Every state is a WORD with its register (data-register from apps/core/chips.py, never chosen here); nothing in the row says «approved». The action names WHAT it does; a piece that is not the person's to provide offers «Consulter», and the Conditions gate is stated on the row that it blocks, with the link that resolves it. Contract: `row` = one entry of documents.presenters.register_rows (title, state, state_label, state_reason, responsible, responsible_note, responsible_glyph, due_date, is_overdue, urgency, health, mandatory, current, version_count, may_file, action_blocked, detail_url); optional `compact` (True on the dashboard: identity · state · due only — no responsible, no action, no menu, no reason; the register page carries those). {% endcomment %}
