{% comment %} Badge — a short label with its register, for the includes that name a `kind`. Contract: `label`, optional `kind` in neutral|info|primary|success|warning|error|pending|soon|overdue. It IS a chip (templates/components/chip.html, through the {% chip %} pair): the kind is translated once, by core.chips.KIND_REGISTER — success → conforme (ink and a plain disc: never green and never a check, because this platform approves nothing), warning → attesa, error → rifiuto, pending → esame, soon → attesa, overdue → azione, everything else → neutro — and the mark is the register's, never a glyph the caller picks. The `badge` class is a hook for the pages that place it; no rule paints it. {% endcomment %}{% chip register=kind|badge_register css_class="badge" %}{{ label }}{% endchip %}
