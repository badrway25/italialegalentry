{% load i18n %}{% comment %} Language control of the V4 header (docs/design-v4/CREATIVE_DIRECTION.md §3.2): a segmented control of four links — FR · IT · EN · ع — with the current language as the raised thumb. Plain links, no script: choosing a language is a navigation, and the page reloads in it. Each link carries lang / hreflang / dir so screen readers switch voice, and its accessible name is the language's own name; the two-letter code is presentation (uppercase by CSS, so the text node stays the ISO code the Arabic-chrome audit already allows). Links come from the `site.languages` context processor (translate_url of the current page), like components/language_switcher.html, which remains the control of the drawer and of the platform bar. {% endcomment %}
