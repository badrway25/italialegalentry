{% comment %} Homepage section header — the FOLIO (art direction A §7.2), which replaces the eyebrow entirely. The page this replaces carried six eyebrows on one screen, all at the same size, weight, tracking and colour, so none of them told the reader anything except "a section starts here". The folio says three things instead: WHERE you are (an ordinal), WHAT this is (the running head) and WHEN it was revised or from which source it comes. The ordinal is a CSS counter and is PRESENTATIONAL: the anchor is always the section's slug, so reordering the home page from the back-office never breaks a link to it.
