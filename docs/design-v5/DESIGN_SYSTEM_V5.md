## 1. Architecture

### 1.1 Three layers, one direction of reference

| Layer | Names | Read by | Rule |
|---|---|---|---|
| **1 · Primitives** | `--p-<material>-<step>` (colour), `--s-*` (space), `--radius-*`, `--dur-*`, `--curve-*`, raw font stacks | layer 2 only | never read by a component sheet (a test greps component sheets for `var(--p-`) |
| **2 · Semantic** | `--surface-*`, `--text-*`, `--line-*`, `--accent-*`, `--focus-*`, `--identity-*`, `--scrim-*`, `--tone-<register>-*`, `--aud-*`, `--shadow-*`, `--glass-*`, `--motion-*`, `--ease-*`, `--f-*`, `--t-*` / `--u-*` | components | named by *function*, never by colour |
| **3 · Component** | `--btn-*`, `--chip-*`, `--field-*`, `--card-*`, `--overlay-*`, `--rail-*`, `--nav-*`, `--loader-*`, `--journey-*`, `--notice-*`, `--deadline-*`, `--node-*`, `--seal-*`, `--toast-*` | the component's own sheet | re-pointed by context (`[data-register]`, `.on-inverse`, `body.console`, `:lang(ar)`) — never by a template |

The brand colours `--brand-green #157A3C`, `--brand-navy #0F2547`, `--brand-red #C4142B`, `--brand-gold #C39A2B` stay declared **once**, in `static/css/v2/tokens.css` (an existing test forbids a second declaration); V5 only references them.

### 3.2 The eight tones (state registers)

Each register exposes the same eight semantic steps. **`conforme` is ink, without chroma** — the repository's rule, enforced by `tests/frontend/test_chips_registry.py` and kept (`RED_TEAM` B1); the seven chromatic registers are generated identically (`esame`, `neutro` ← deposito, `attesa` ← ambra, `azione` ← cotto, `rifiuto` ← granata, `blocco` ← grafite, `nullo` ← cenere).

```css
:root {
  /* conforme — INK, no chroma (OKLCH C of the mark 0.024; test ceiling 0.03) */
  --tone-conforme-bg: var(--p-carta-100);            /* word/mark 13.59:1 */
  --tone-conforme-bg-hover: var(--p-carta-150);
  --tone-conforme-edge: var(--p-inchiostro-400);     /* 3.37 on carta-50, 3.74 on white */
  --tone-conforme-mark: var(--p-inchiostro-900);     /* the plain filled disc — no glyph */
  --tone-conforme-text: var(--p-inchiostro-900);
  --tone-conforme-night-bg: var(--p-notte-800);
  --tone-conforme-night-text: var(--p-notte-50);     /* 11.82 */
  --tone-conforme-night-mark: var(--p-notte-50);
  /* … the same eight names for esame, neutro, attesa, azione, rifiuto, blocco, nullo, from their tones */
}
```

| Register | Tone | Asserts | Edge style | Pattern | Mark («i cerchi») | word/body · mark/carta-100 |
|---|---|---|---|---|---|---|
| `conforme` | **ink** (inchiostro-900 on carta-100; no chroma) | a fact is recorded as conforming — never a verdict | solid | solid | **filled disc, no glyph** | 13.59 · 13.59 |
| `esame` | esame (wisteria) | in the hands of an intervener | solid | solid | half-filled disc | 7.21 · 3.69 |
| `neutro` | deposito (slate) | a fact; nobody must act | solid | solid | ring + centre dot | 7.22 · 4.93 |
| `attesa` | ambra | due, not late | **dashed** | **hatch** | dashed ring (MANQUANT) · ring + two arrows (À REMPLACER) | 7.25 · 3.31 |
| `azione` | cotto (terracotta) | a named actor must act now | solid | solid | filled disc + clock hands | 7.18 · 5.00 |
| `rifiuto` | granata (garnet) | refused / invalid, with a reason | solid | **dots** | filled disc + × | 8.78 · 7.01 |
| `blocco` | grafite | a dependency, heavy and calm | solid | **cross-hatch** | lock | 11.34 · 9.08 |
| `nullo` | cenere (ash) | withdrawn, not applicable, archived | **dotted** | outline only | slashed dotted ring | 5.38 · 3.13 |

Weakest pairs, stated (`COLOUR` §10): rifiuto/blocco marks under protanopia ΔE 0.030 and attesa/azione words under deuteranopia ΔE 0.015 — separated by mark shape, pattern and edge style, which are therefore load-bearing. `conforme` (ink) and `neutro` (slate) marks differ by 2.76:1 and OKLab ΔE 26: shape (filled disc vs ring + centre dot) and word carry the difference. The lapis `registro` steps remain for the information notice only (§4). The contrast values of the `conforme` row were computed in this revision (`scratch/ecd/revision/colour_check.py`); `verify_tokens.py` must be re-run on the whole amended file in F2.

| Function | Timing | Curve / spring | Examples |
|---|---|---|---|
| feedback (hover, press, focus) | 120 in / 120 out; press down 0, release `--spring-snappy` | exit in, enter out | buttons, rows, links |
| state (chip, tab, tooltip) | out 120 / in 200 | exit / enter (chips `--ease-layout`) | status change, panel swap |
| space (drawer, modal, reveal, image) | 320; exit 200 (drawer) / 120 (modal) | enter / exit; sheets `SPRING_SHEET` | overlays, sections |
| story (page cross-fade) | 120 (public View Transitions, measured gate) | enter | navigation |
| draw (once) | 900, stagger 120 | enter; the light `--ease-sine` | arch light, JourneyRail |
| working (loaders) | 1200 / 1600 / 2200 cycles | linear phases with the turn curves | L2 / L1 / L3 |
| first breath (once) | arch 900, then four route lights 1200 each, 400 apart (≈ 3.3 s in all) | `--ease-sine` | the hero after LCP — then rest; **no ambient loop exists** |

Choreography rules (MOTION §4, binding): container before content (content from 120 ms, 4 px, stagger 40, ≤ 6 items); reading direction for panels, wizard, thread and route light; exits faster than entrances; a sequence ≤ 600 ms except draw and scroll-bound light; no delay > 100 ms except the 400 ms wait threshold and the tooltip; the chrome stays still; one live object per page; state before motion; hover only under `(hover: hover)`; never on text in the first viewport, never on the LCP element, never on `<main>`; everything infinite pauses off-screen and on a hidden tab (the only infinite motions left are the loaders while a wait lasts and the videos, which carry a Pause toggle). Allowed properties: `transform`, `opacity` (and `clip-path` one-shot); forbidden in animation: `filter`, `backdrop-filter`, `box-shadow` (except the one-shot 320 ms node light), `width/height` (except the rail toggle after `is-ready`), `top/left`, `background-position` on large areas, `stroke-dashoffset` and `offset-distance` for anything looping, scroll-linked or loading.
