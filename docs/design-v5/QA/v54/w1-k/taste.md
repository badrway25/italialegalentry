## How I read the anchors

1. The scale is §3.1 item 1's; «six-point» I read as DL54-03's six scales, three of them this lens's; halves only where the instrument splits between two anchors, as the design chair's anchors do (`he_design.md` §8.3).
2. A 4 needs both the instrument held without a «No» and the still credible beside the family's named references: the instrument is necessary, the anchor decides — no faults and no costly thing done right is a 3.
3. Visual: Q3 and Q4 «Yes» → 4; one «Partly» → 3.5 when it is finishing (values off the scale, measure), 3 when it is composition (a floating object, a remainder); a «No» → 2.5 at most.
4. Premium: «No» on Q1 and Q2 → 2.5; with no «No», count Q1's four costly things actually done right and whether the swap holds on every still — near-yes on both → 3.5, near-no → 3.
5. Originality: the swap test per still decides — every still, a named carrier, no tell-tale co-carrying → 4; every still with a portrait-B tell-tale co-carrying → 3.5; desktop only → 3; a signature present that carries nothing → 2.
