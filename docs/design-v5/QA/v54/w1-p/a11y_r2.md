### Minor

**n1. From 48 to 90 rem the home link is named «V5» alone.** This touches WCAG 2.4.4 and 2.4.6, and it is a side effect
of the fix round's new tiers.

- **Where.** `designpreview.css:1724–1728` hides `.dp-strip__ile` («Italy Legal Entry™ — ») with `display: none` below
  90 rem. The lockup's mark is `alt=""`, and its wordmark is `display: none` in the strip. What is left of the link's
  text is «V5».
- **Measured** (E/05), on the landing and on the index. Chrome names `.dp-strip__home`:
  - «Italy Legal Entry™ — V5» from 1440 to 1919;
  - «… — V5, la migliore di oggi» from 1920, and below 48 rem, where the name comes from the `title`;
  - but only **«V5» at 1280, 1024 and 768.**

  In round 1 it read «Italy Legal Entry™ — V5» all the way down to 48 rem. The 1280–1439 range is the owner's 1440
  screen at 100–112 % zoom.
- **Fix.** Hide the words from the eye only, as the sheet already does for `.dp-strip__who` below 48 rem:

  ```css
  @media (max-width: 89.99rem) {
    .dp-strip__ile {
      position: absolute;
      inline-size: 1px;
      block-size: 1px;
      overflow: hidden;
      clip-path: inset(50%);
      white-space: nowrap;
    }
  }
  ```

  An absolute box of 1 px takes no room in the row, so the measured tiers do not move.
- **Test to add.** At 1024 × 768, `page.get_by_role("link", name="Italy Legal Entry™ — V5")` is visible in the strip.

**n2. «1:1» is named «1:1», and it can be pressed while there is no desktop frame.** This touches WCAG 2.4.6 and 4.1.2.

- **Where.** `index.html:141` and `designpreview.js:533–536`.
- **The name.** Chrome reads a button «1:1», not pressed, whose purpose comes only as a description, from the `title`:
  «La cornice desktop alla sua misura vera, senza ridurla». A voice reads «one colon one», and not every screen reader
  reads the description.
- **The state.** With the desktop frame released, pressing «1:1» sets `aria-pressed="true"` and nothing on screen changes
  (E/03, `4_true_size_pressed_without_desktop`).
- **Fix.**
  - The name: write `1:1<span class="dp-hidden"> — misura vera della cornice desktop</span>`. The visible label stays
    first (2.5.3).
  - The state: in `pressed()`, set `trueSize.disabled = !held.frames.some(function (item) { return kindOf(item) ===
    "desktop"; });`.

**n3. Forced colours erase the pressed state of the viewer's three toggles.**

- **Where.** `designpreview.css:2445–2449` marks `aria-pressed="true"` with a background (`--accent-dark`), and the
  forced-colours block (`:2515`) does not cover it.
- **Measured** (E/07_forced_viewer_bar_1440.png). Under emulated `forced-colors: active`, «Desktop 1440» (pressed) and
  «Telefono 390» / «1:1» (not pressed) all draw Canvas behind CanvasText. Only the border's hue differs: rgb(55, 0, 110)
  against black.
- **Why it matters.** Since m5, these are true toggles, so their state is the information they carry.
- **Fix.** Add to the existing block:

  ```css
  @media (forced-colors: active) {
    .dp-viewer__button[aria-pressed="true"] {
      forced-color-adjust: none;
      border-color: Highlight;
      background: Highlight;
      color: HighlightText;
    }
  }
  ```

**n4. «Superfici V5» is named «Superfici V5 13»: the count has no words around it.**

- **Where.** `_strip.html:39`.
- **Measured** (E/04). Chrome reads a DisclosureTriangle named «Superfici V5 13». Read aloud, «V5 13» runs together; what
  the pill means is visual only.
- **Fix.** `Superfici V5 <span class="dp-strip__count"><span class="dp-hidden">: </span>{{ strip.quick.count }}<span
  class="dp-hidden"> pagine</span></span>`. The name becomes «Superfici V5: 13 pagine», and nothing visible changes.

**n5 (latent). Under the WCAG 1.4.12 override, «V5 — council-passed» is cut short at 100 rem, and at 390 px and below.**

- **Why it is latent.** It happens only when the framed page's surface is `"v5"`, and none is today. With «V4 + fondation»
  the words fit at 1600 (E/10).
- **Measured** with a scratch status that marked the home `"v5"` (E/10_state_clip.json):
  - **With the override, at 1600–1620,** the tier where the build appears: «V5 — council-…» at 1600 and «V5 —
    council-pas…» at 1620 (E/10_state_clip_spacing_1600.png).
  - **With the override, at 390 px and below:** «V5 — counci…» at 320, «V5 — council-…» at 340–360, «V5 — council-pa…»
    at 375 and «V5 — council-pas…» at 390.
  - **Without it:** only at 320, «V5 — council-pas…».
- **Why it is only minor.** «V5» always shows, and the full words stay in the chip's accessible name and tooltip.
- **What the notes say.** The implementation notes give the ellipsis for «V5» only at 320 and 360 (with a persona
  inside), and under the override only for «V4 + fondation», at 375 px and less. The 1600–1620 case is not mentioned.
- **Fix.**
  - **Let the build yield before the state.** Today the build cannot shrink: it is a flex item with `min-width: auto`
    and no-wrap text. Its words are repeated in «Novità». So:

    ```css
    .dp-strip__build {
      flex-shrink: 100;
      min-inline-size: 0;
      overflow: hidden;
      text-overflow: ellipsis;
    }
    ```

  - **Below 48 rem, decide it with design.** Either show a shorter visible label, with the full words kept in the name,
    or keep the ellipsis. Record the choice in the notes.
  - **If the UX re-check's n5 lands** (tiers that follow what the row holds), keep the rule above, so that under the
    override it is still the build, not the state, that yields.
- **Then re-measure** the 54 rows with «V5 — council-passed» in the frame.

  - 3 mentions inside Italian sentences of the index.
- **Why it is only minor.** «V4 + fondation» is the plan's label (§4.1), close to a proper name. What it costs is an
  Italian voice reading «fondation».
- **Fix.** Give the label its language wherever the state is V4:
  - In `_row.html` and `_family.html`: `<span class="dp-state dp-state--{{ row.state }}"{% if row.state != "v5" %}
    lang="fr"{% endif %}>` (with `family.state` in the second).
  - In `_strip.html`: the same on `.dp-strip__state-label`.
  - In `follow()` (`designpreview.js:210–213`), beside `words.textContent`: `if (state === "v5") {
    words.removeAttribute("lang"); } else { words.lang = "fr"; }`.
  - Optionally, `lang="en"` on «V5 — council-passed».

  through CSSOM, because the page's CSP refuses an inline `<style>`. Zoom levels were approximated by widths.

  connected: **15 passed, 0 skipped**, in 70 s (`E/12_pytest_browser.log`).

    strip with 2, 6 and 12 surfaces for M2, and the release asserted in the frame-cap test for m5.
