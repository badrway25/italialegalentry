## 5. DECISIONS THE CD / OWNER MUST TAKE

1. **Arch silhouette outside the hero** (`.portico-reveal`, optional arch-top crops on the four doors) conflicts with V4 pillar 2 («full arch only in hero and login»). Proposal: allow the silhouette as a motion/mask on ≤ 2 image moments; otherwise restrict it to the hero exit.
2. **Photo count**: V4 caps the home body at ≤ 5 photos. This proposal needs ≈ 11 on the home (portico 1, doors 4, process 3, bento 1, forum 1, news ≤ 1), all lazy and below the fold, 480w on mobile. The feature-section pattern is kept for inner pages. That makes the home «image-rich» without touching LCP, but it costs data on slow 4G. Needs an explicit cap change.
3. **Footer closure**: the arch-and-steps outline by default. The oversized official wordmark only with owner sign-off (BRAND_ASSETS). The wordmark font is kept in both cases.
4. **Light-surface route tokens**: only `--route-n-dark` exist. The doors need light variants checked at ≥ 3:1 for graphics, or a dark chapter.
5. **Golden key travelling the process route** (#24556) is an optional signature. Its risk is looking playful, so the CD decides.
6. **RTL of the process route**: keep the path unmirrored so the Morocco→Italy geography stays true, and mirror text only.
