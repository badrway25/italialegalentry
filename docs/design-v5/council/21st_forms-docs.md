# 21st.dev curation — Forms and document workspace (ILE V5 council)

Curator: 21st.dev Component Curator, family «Forms and document workspace», for the Executive Creative Director. Date: 26 Sept 2026. The repository was read and not modified (`C:/tmp/italylegalentry`, HEAD `df8dc42`, working tree as found). The 21st.dev account is on the paid tier. Tools used: `search` and `get_inspiration`, which return metadata, and `get_component`, which returns code. `generate` and `iterate_generation` were **never called**.

Method: inventory (templates/components, documents, helpdesk, companies, allauth, v4 CSS, DS V4 §7–§8, CD §3.5), then semantic context, then 28 lookups, then ≥5 candidates per component, then visual review of 54 preview images and code review of 15 components, then a selection and an ILE route for each component. Every candidate URL and preview URL in §2b was checked afterwards: all 259 return HTTP 200.

Continuation (same day, second session): lookups 25–28 were added to bring the flagship C17 to ≥8 dedicated candidates and C16 to ≥5, as the brief requires. Nine candidates, three code retrievals and one contact sheet were added; the selections of C16 and C17 were refined, no other row changed.

**Scores** (1–5) use the order **I/P/A/Pf/D**:
- **I**: institutional / legal-tech fit
- **P**: premium quality
- **A**: accessibility
- **Pf**: performance and dependencies (5 = no dependency, tiny)
- **D**: Django adaptability (5 = drops into a server-rendered template)

**Routes:**
- **A**: adapt to Django + CSS + small vanilla JS
- **B**: use the Motion JS library already bundled
- **C**: React island
- **D**: reject

No component in this family justifies route C.

**Four repository facts that decided several choices.** Each was verified in `config/settings/base.py` (CSP):
1. `img-src 'self' data:` has no `blob:`. Local thumbnails of chosen files (`URL.createObjectURL`), which 27137, 19200 and 29545 show, would be blocked. There is also a privacy reason not to show them: they would be identity papers.
2. `frame-ancestors 'none'` and `object-src 'none'` stop the platform from embedding its own PDFs in an iframe or `<object>`. Viewers that ship PDF.js or WASM (15406, 2090) also break the budget and the CSP.
3. `style-src 'self'` blocks the inline `<style>` that 26824 injects. Template `style=""` attributes are also out, so dynamic widths must be set through the CSSOM or with `<progress>`.
4. `connect-src 'self'` allows a same-origin `XMLHttpRequest` upload, which gives real byte progress. `fetch` has no upload progress.

## 4. What I could not do, and open points

**Limits of the visual review:**
- The visual review used the static preview images, 54 of them in 6 contact sheets. No live demo was opened and no preview video was watched.
- 27137's preview shows only the closed trigger. Its upload UI was judged from its code.

**Scores and estimates:**
- Scores are the curator's judgement. They were not produced by a measured audit of each candidate.
- Bundle sizes for the proposed ILE modules (≈0.2–4 KB gz) are estimates. Nothing was built or measured, because this phase is read-only.

**Code coverage:** code was retrieved for 15 candidates: the flagship shortlists and the key idea sources. The other scores come from their descriptions and previews. 29469 and 29345 were scored from preview and description only.

**Catalogue limits:**
- `get_inspiration` ran without an ILE design context (`contextApplied: false`). Its ranking is generic.
- The catalogue is noisy: about 60 % of «advanced table» results were AI-agent widgets.
- Result counts include duplicates across queries.

**Decisions for the owner or backend:**
- C9 needs a JSON response branch in the documents upload views.
- An inline PDF renderer in C12 would need CSP and security changes (`frame-ancestors`, and possibly `worker-src`/`wasm`). It is not proposed.
- The C17 group titles need a copy decision limited to enum words.
- 26871 (folder silhouette as a «fascicolo» tile) is an identity question for the ECD.

**Not in scope for this family:** skeletons, empty states, toasts, the tabs/segmented thumb physics shared with navigation, date pickers, and the wizard stepper. Other curators own them. Only the touch points are noted here.
